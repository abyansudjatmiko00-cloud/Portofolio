# ABYANNZ. — Personal Portfolio

Website personal portfolio yang dibuat menggunakan Next.js untuk menampilkan profil, kemampuan, project, perjalanan belajar, dan memories.

## 🌐 Live Website

https://portofolio-abyanzz.vercel.app

## 🛠️ Teknologi yang Digunakan

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
- Next/Image

## ✨ Fitur Website

### 1. Portfolio

Website memiliki beberapa halaman utama:

- Home
- About
- Projects
- Journey
- Journey Archives
- Project Detail

Navigasi antar halaman menggunakan `next/link`.

### 2. Responsive Design

Website dibuat responsive untuk berbagai ukuran layar dan mendukung tema terang dan gelap.
